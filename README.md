Application for Arduino driving 32x16 dot matrix LED bought at Digit in Osaka Japan.
This LED module is using 3 shift resisters called BD7851FP from Rohm.
These are the list of application for Arduino
1. dspAlfa5x7_test : display fixed alphabetical characters from hankaku_v.h
2. dspAlfa5x7_shift : display 2 line of strings and scroll.
3. dspPattern_v1 : display graphic pattern the code from hedder file which is made by mkPattern.exe
